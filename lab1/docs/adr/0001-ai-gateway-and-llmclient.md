# ADR-0001. AI Gateway и интерфейс LlmClient

- **Статус:** принято
- **Контекст:** сервис анализа отзывов зависит от LLM. Прямой вызов конкретного провайдера из бизнес-логики
  создаёт vendor lock и размазывает логику ошибок, логирования и метрик по коду.
- **Решение:** интерфейс `LlmClient` (`providerName()`, `generate()`), реализации `OpenAiLlmClient` и
  `InternalLlmClient`, единая точка входа `AiGateway`, выбирающая провайдера по `llm.active-provider`.
  `service` знает только про `AiGateway`.
- **Рассмотрено и отклонено:** вызов OpenAI прямо из `service` (vendor lock, нельзя протестировать без сети);
  выбор провайдера внутри `service` через `if/else` (бизнес-логика узнаёт про инфраструктуру).
- **Последствия:** смена провайдера — правка конфигурации; новый провайдер — один новый класс.
  Цена — дополнительный слой индирекции.
