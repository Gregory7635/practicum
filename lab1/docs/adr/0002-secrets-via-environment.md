# ADR-0002. Секреты только через переменные окружения

- **Статус:** принято
- **Контекст:** API-ключ внешнего LLM — секрет; закоммиченный ключ считается скомпрометированным.
- **Решение:** в `application.yml` только ссылки `${OPENAI_API_KEY:}` с пустым значением по умолчанию.
  Ключ передаётся окружением при запуске. Если ключ не задан, `OpenAiApiClient` не делает HTTP-вызов,
  а сообщает об ошибке конфигурации, и `AiGateway` отрабатывает fallback.
- **Рассмотрено и отклонено:** ключ в `application.yml` или в `application-local.yml` в репозитории;
  ключ в коде как константа.
- **Последствия:** репозиторий безопасен для публикации; локальный запуск с реальным провайдером требует
  `export OPENAI_API_KEY=...`. Запуск по умолчанию (`internal`) ключа не требует.
